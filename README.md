# Sohu AIGC Content Lab

个人独立求职作品，非搜狐官方。未使用搜狐内部数据；未接入模型。当前为可运行 MVP。

## 启动
安装 Node.js 后，在本目录执行 `node server.cjs`，浏览器打开 http://127.0.0.1:4173 。也可双击 dist/index.html，但建议使用本地服务，浏览器本地文件存储行为可能不同。

## 已实现
资讯素材与出处输入；三类可导出 Prompt；本地抽取规则演示；真实模型输出人工回填；长度、数字、用词、来源字段检查；人审状态与说明；本地记录保存、删除；JSON/CSV 导出；真实与模拟分离的策略看板；90条未运行实验任务导出。

三策略：A 基础指令；B 结构化约束；C 证据优先与自检。规则演示只展示流程，不能比较模型策略效果。自动检查不能替代逐句事实核验。

## 数据与限制
初始真实实验数为0；演示素材明确虚构。真实回填标识是用户声明，系统未验证调用。模型名称和运行记录 ID 必填；具体参数与原始请求/响应需另存为实验附件。记录仅存当前浏览器 localStorage，导出 JSON 可保留原文与完整 Prompt；MVP 暂无导入、云同步、用户账号、在线生成和发布功能。勿录入敏感或无授权的素材。

## 部署
这是无依赖静态网页。任何静态托管服务的发布目录均为 `dist`，无需构建命令。Sites 使用 `.openai/hosting.json` 中的项目 ID 与静态目录；默认私有，分享给招聘方前需另行设置访问权限。公开部署前也应检查素材授权与个人信息。API 密钥不能写入前端；下一版模型接入应经过服务端代理及环境变量。

## 验证与后续
语法检查：`node --check dist/app.js` 与 `node --check server.cjs`。功能验收：载入样例→运行规则演示→检查→保存→看板显示模拟1、真实0→导出→刷新保留→删除。真实实验方案见 EXPERIMENT.md，作品集与简历描述见 PORTFOLIO.md。
